aiofarmad
=========

Async Python client for the Mijn Farmad Apotheek customer API. Requires Python >= 3.14.

.. warning::

   This library is unofficial and reverse-engineered. It is not endorsed by
   Farmad, and it may break without notice whenever Farmad changes their API.
